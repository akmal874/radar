# Simulator Radar ARPA

Simulator radar kapal (X/S-band, ARPA, AIS, SART) untuk latihan pengoperasian radar dan ujian praktik taruna nautika. Aplikasi berupa satu file `index.html` dan berjalan di browser Windows, macOS, Linux, Android, dan iOS.

Dibuat oleh **Akmal Iskandar, S.Pi**. © 2026. Seluruh hak cipta dilindungi.

## Fitur
- Kontrol radar lengkap: GAIN, SEA (STC), RAIN (FTC), TUNE, BRILL, range, pulsa, H UP / N UP / C UP, RM / TM, off center, IR, echo stretch, echo average, trails, EBL/VRM, guard zone, index line.
- ARPA (CPA/TCPA, vektor true/relatif, alarm), overlay AIS, Radar-SART dan AIS-SART.
- 5 skenario latihan dengan penilaian otomatis, lembar hasil PDF, riwayat nilai dan ekspor Excel/PDF.

## Cara pakai
Buka alamat web aplikasi di browser. Nilai latihan tersimpan di browser perangkat masing-masing dan dapat diekspor ke Excel/PDF.
